# grandeTrend

横屏安卓成绩趋势应用。原生 Kotlin / Jetpack Compose，纯黑背景、荧光成绩折线、淡色总排名柱，数据离线保存在本机 SQLite。

## 安装

支持 Android 10 及以上（API 29）。当前版本 1.3.0，安装 `dist/grandeTrend-v1.3.apk`，应用名称为「成绩趋势」。使用与首版相同的本机 Android 测试签名，可直接覆盖更新；**不要先卸载或清空应用数据**。包名和签名固定，打包脚本校验证书摘要，防止误换密钥。现有私钥需安全备份，不能直接换新密钥给已安装的首版更新。

首次启动没有示例成绩。先点左下角「常用科目」，再点「新增 / 修改」录入考试。编辑已有考试时，切换到「修改考试」；默认选中图表当前考试，可切换其他考试。

## 使用

- 点「总分」看首页，滑动左侧学科滚轮或点可见学科切换单科。滚动过程中中心科目、图表和摘要同步切换，停下后自动吸附。
- 「常用科目」决定新增默认值，添加页「本场科目」只影响本场。左侧滚轮始终包含历史考试涉及的科目，临时加科不会变得无法查看。
- 「单次考试」查看当前考试，前后切换、进入编辑或删除。三科及以上用雷达多边形展示得分率，少于三科用条形图；支持裸分/赋分切换，按本场各科满分计算，并列出原始成绩。未公布处留空，零分保留，超满分扩展坐标。
- 单次考试页的「删除」或修改页的「删除此考试」经确认后，只删除本场考试与其成绩；取消不写入，其他记录及设置保留。删除最后一场后回到首次录入页。
- 各指标独立勾选，各科的选择分别记住。图中点或柱对应一场考试，点击后顶部成绩、排名和日期同步更新。
- 「全部考试」可以改为学期或两场考试之间的自定义范围。双指缩放，放大后左右拖动；点「显示全部」恢复筛选范围内的全部考试。
- 满分逐场保存。裸分和赋分可以留空，零分需填 `0`；空值不绘图，折线在缺失处断开。
- 新增/修改页采用自定义双栏布局：左侧考试信息、备注与本次选科，右侧成绩表和官方总分/排名；两侧分别滚动。日期滚轮、历史考试选择和超分核对统一为黑底荧光风格。输入法完成键收起键盘后可保存。
- 总分自动求和，官方总分可覆盖计算值。任一所需成绩缺失时自动总分为空；不会用裸分补齐缺失赋分。两种总排名均手动填写。
- 「导出单科」可选多个科目，每科生成一张独立黑底 PNG。可导出当前可见考试或当前筛选的全部考试，图片附成绩明细和该次满分。
- 图片保存在系统相册的 `Pictures/grandeTrend`，保存成功后可打开系统分享界面。无需登录、联网或存储权限。
- 「数据备份」可导出全部考试和设置为 JSON 文件，由系统文件界面选择保存位置；与图像导出分开，不受图表范围限制。
- 选择 JSON 备份后先预览，再确认导入。默认合并新考试、保留同 ID 的本机记录；可明确选择覆盖同 ID 考试和恢复选科/显示偏好。重复导入不会新增重复 ID，不删除本机其他考试。
- 导入前自动留一份本机快照，可通过同一界面的「导出最近一次导入前的备份」保存到外部。重要备份应保存到手机文件或其他设备；卸载或清空应用数据会删除本机成绩与自动快照，之后可从外部 JSON 恢复。

## 构建

需要 JDK 17、Android SDK Platform 35 / Build Tools 35.0.0。Android Studio 可直接打开项目。

1. 将 Android SDK 路径配置到本机 `local.properties`（`sdk.dir=...`），或设置 `ANDROID_HOME`。
2. 设置 `JAVA_HOME` 指向 JDK 17。
3. 执行：

```bash
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK 输出：`app/build/outputs/apk/debug/app-debug.apk`。

生成与本次交付相同的优化、测试签名安装包：

```bash
./scripts/package-preview.sh
```

此脚本使用本机默认 `~/.android/debug.keystore`，私钥不会复制进项目；校验摘要在 `dist/SHA256SUMS`。签名必须匹配公开的 `scripts/preview-signing-cert.sha256`，否则脚本中止并保留已交付包。

连接模拟器或测试设备后执行：

```bash
./gradlew :app:connectedDebugAndroidTest
```

仪器测试会清空**被测试安装实例**的成绩数据库，务必只在专用模拟器或无真实成绩的设备中运行。测试记录不会进入交付应用的初始数据。

验证原交付 1.2 到当前 1.3 的实际覆盖安装：

```bash
./gradlew :verification:assembleDebug
./scripts/verify-update.sh emulator-5580
```

也可验证首版直接升级：`./scripts/verify-update.sh emulator-5580 dist/grandeTrend-v1.apk dist/grandeTrend-v1.3.apk 1 4 docs/verification/v1.3/from-v1`。

替换为专用模拟器的实际序列号。此脚本仅允许模拟器，会先清除该模拟器的应用安装以准备旧版测试数据，再进行不卸载、不清空数据的新版覆盖安装。`verification` 是独立的升级测试工具，不进入交付 APK。

## 项目说明

- `SPEC.md`：产品需求原文。
- `docs/implementation.md`：首版采用的建议默认与架构决策。
- `docs/verification.md`：本次构建、核心验证、适配结果和边界。
- `docs/data-safety.md`：1.1 备份格式、合并恢复规则、覆盖更新与后续迁移要求。
- `design-qa.md`：参考图与原生应用截图的视觉对照。
- `app/src/main/.../domain`：分数、总分、空值、排序、范围与视口逻辑。
- `app/src/main/.../data`：SQLite 保存、JSON 数据备份恢复与 MediaStore PNG 导出。
- `app/src/main/.../ui`：主界面、滚轮、表单、图表和导出交互。
