# 数据导入导出与更新规则

## 使用

首页右下角「数据备份」提供「导出全部数据」和「选择备份导入」。原有「导出单科」仍用于生成 PNG，图片不是可恢复的数据备份。

备份为 UTF-8 JSON，使用 Android 系统文件选择器保存到用户选择的位置，不需要存储权限。导出的文件包含全部考试（包括常用科目以外的历史科目），不受学期筛选、缩放或图表指标影响；包含 ID、名称、日期、学期、顺序、备注、每科当次满分、裸分、赋分、单科排名、两种官方总分及排名，以及个人选科与各视图指标偏好。

导入先校验全部内容并显示考试数量、新增/重复数量、时间范围。默认按 ID 合并：新增 ID 加入，相同 ID 保留本机考试，不删除备份以外的本机考试。勾选「覆盖相同 ID」才更新重复 ID；勾选「恢复备份中的选科和显示设置」才恢复偏好。首次空数据且尚未配置选科时默认恢复偏好。重复导入同一文件不会制造重复考试；不同 ID 即便同名同日，也视作不同考试。

导入前以 AtomicFile 保留完整本机快照，并读回核对。无法完整保存快照时中止导入；成绩与设置在同一 SQLite 事务中写入，任一写入失败整体回滚。「导出最近一次导入前的备份」可把自动快照保存到手机文件，再按上述流程导入恢复。自动快照只保留最近一次，并会随应用卸载或清空数据一起移除；重要备份应导出到外部位置。

本版只支持本应用 JSON 备份，不接受 CSV、Excel、PNG 或其他应用的数据库。格式版本为 1，未来未知版本拒绝读取。文件上限 10 MiB、考试上限 10000 场；超限明确报错，绝不静默截断。分数用字符串保存，空值用 JSON null，排序序号用整数字符串，避免浮点数损失。损坏文件（包括非法 UTF-8）、未知学科、重复 ID/科目、非法排名/分数或偏好拒绝导入。

## 主动删除考试

删除必须在应用中明确确认目标名称和日期。SQLite 外键级联在同一个事务中移除本场考试和成绩，不改动其他考试或任何偏好；取消不写入，失败回滚。旧的外部完整 JSON 备份仍包含当时的考试，可合并导入恢复已删除记录。应用没有撤销删除或删除前自动快照；需恢复时使用此前导出的完整数据备份。

## 覆盖更新

- 应用 ID 永久保持 `com.grandetrend.app`；当前版 versionCode 4 / versionName 1.3.0（1.2 为 3 / 1.2.0）。1.3 更新滚轮、选科、删除及单次考试展示，继续沿用备份格式 1 和数据库版本 1。
- 保留首版签名。打包脚本将证书 SHA-256 与 `scripts/preview-signing-cert.sha256` 比较，签名不同则不产出交付包。该文件只包含公开证书摘要；私钥仍在本机 Android keystore，需另行安全备份。
- 使用原来的 `grades.db` 与数据库版本 1。此次新增功能无需结构变化，覆盖安装直接读取原库。
- 后续改表必须递增数据库版本、添加逐版本迁移并验证旧数据；禁止删除重建。当前未知迁移会报错并保留数据库，不会静默将未迁移数据库标成新版本。
- 正常更新通过同签名 APK 直接覆盖安装，**不要先卸载或清空应用数据**。不能随意更换签名；设备不同或已卸载时使用已导出的 JSON 恢复。
- 每个新版交付前在专用模拟器验证旧版保存成绩和偏好、实际覆盖安装、重新启动、逐字段/数据库摘要一致。仪器测试只在测试设备运行。

## Android 平台依据

- [系统文件选择器](https://developer.android.com/training/data-storage/shared/documents-files)：创建/打开文档，不需广泛存储权限，外部文档不随应用卸载删除。
- [应用更新规则](https://developer.android.com/google/play/app-updates)：包名和签名保持一致。
- [SQLiteOpenHelper](https://developer.android.com/reference/android/database/sqlite/SQLiteOpenHelper)：数据库版本变化时执行明确迁移，已发布的迁移步骤不可倒改。
