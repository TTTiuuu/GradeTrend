## 图表与界面

预览图是 UI 参考，不作为栅格背景贴图。界面全部由原生组件组成，成绩曲线与排名柱由数据实时绘制。没有需要另行生成的照片或插图；图标使用 Google Material Icons（Apache 2.0），字体使用 Android 系统 sans-serif / 中文字体。

总览的两种排名为并排柱，柱底固定在绘图区底部，右轴反向，名次越好柱端越高。单科排名使用折线。左右轴分别根据各自显示的数据计算范围。缺失数据无点、无柱，折线断开，不跨空值连线。

在总分模式下，整个学科滚轮降低亮度，不出现另一项同等强度的选中科目。单科模式下，中心行放大、边缘淡出。总分按钮固定在滚轮外。

表单滚动区域与底部保存按钮分开，短横屏仍可访问全部字段。软键盘打开时优先展示输入字段；通过输入法完成键关闭键盘后恢复标题、模式和保存操作。新增与修改使用独立模式，修改默认对应当前图表考试，保存以原 ID 更新，不额外插入考试。

1.2 重做新增/修改页：自定义 `EditorDialog`、分段模式切换、按钮、选科块与 `BasicTextField` 输入框。左侧考试信息与右侧成绩表分别滚动，信息标签与输入框同行，增加可见的滚动位置提示；成绩列标题固定，裸分与赋分分别使用荧光绿和青色。输入框约 34 dp、成绩行间隔 5 dp，标题区 46 dp、底部摘要区 52 dp；常规横屏可同时显示六科成绩、四项信息及九个选科选项。总分摘要与保存操作固定在底部，短屏下长摘要省略显示，存储数值不截断。日期使用自定义三列滚轮与选中带，切换考试使用有名称/日期/学期的列表，超分校验使用同风格的确认界面。输入框保留可访问的字段名称、选择状态、输入法完成动作和自动滚动到焦点的行为；文本输入使用用户的系统输入法。

窄屏、短屏或放大系统字体时采用紧凑摘要，简写两种排名并减少图表刻度，防止文字重叠；原始数值不改变。较长的小数根据实际文字宽度自动缩小字号，避免裁切有效数值。

## 持久化结构

- `exams`：ID、名称、日期、学期、两种总排名、两种官方总分、备注与排序序号。
- `scores`：考试 ID、学科、当次满分、可空裸分、可空赋分、可空单科排名；以考试 + 学科为主键。
- `preferences`：个人学科选择与总览/各科的显示指标。

考试与各科成绩在单个事务中保存。数据库版本为 1；后续版本应添加无损迁移，不应采用删除重建。

## 范围边界

首版未添加账号、多用户、云同步、成绩识别、表格导入、删除考试、撤销、备份恢复、PDF 或总览导出。1.1 按用户新要求增加 JSON 完整备份恢复；细节见 `data-safety.md`。1.3 增加明确确认后的删除考试，以及单次考试多边形视图；仍不包含撤销删除、云同步、表格导入或 PDF。

为避免长历史导出耗尽手机内存，单张图片按预计像素内存设置上限；超过上限会明确提示缩小考试范围，不会静默截断考试。不同厂商系统的相册展示顺序和分享目标需在实际手机上进一步确认。

## 1.3 滚轮、选科与单次考试

- `ChoiceWheel.liveSelection` 仅用于主侧栏，观察滚动状态和最靠近中心的条目；拖动/惯性/吸附时立即回调，不依赖松手。首次布局与总分点击不会自动选择科目。日期和范围滚轮仍只在停稳/点击后选择。
- 常用科目存储沿用 `preferences.subjects`，只作为新增默认值；本场科目存于现有 `scores`。导航/导出的候选集为常用科目与历史记录实际科目的并集，不需要改表或回写旧设置。
- `ExamDetailDialog` 自定义双栏，左侧原生 Canvas 雷达，右侧固定表头与可滚动成绩明细；当前范围内前后切换、编辑、删除。修改直接进入目标记录，保持原有 ID、满分和科目。
- 雷达半径使用 `score / maxScore`，保持原分数精度，显示得分率；赋分模式对不赋分科目使用裸分，有赋分科目不补缺失值。四层网格，短横屏或大字体减少刻度标签、将外围得分率集中至明细并压缩摘要区；使用实际窗口尺寸适配。超满分以 25% 步进扩展上限；缺失处无点/无边且不填充，真实 0 在中心。1–2 科采用条形展示，避免退化多边形。
- 删除使用参数化目标 ID 和已启用的 SQLite `ON DELETE CASCADE`，事务内仅删目标及关联成绩。确认取消不保存；删当前记录后优先选择上一场，删别的记录保持原选择；自定义范围端点被删时缩至剩余区间，区间无剩余记录则恢复全部。最后一场删除后进入空状态并恢复全部考试。
- 版本 1.3.0 / code 4，应用 ID、签名、数据库版本 1、JSON 格式 1 不变。
