# 1.2 新增 / 修改页视觉检查

日期：2026-10-04，Asia/Shanghai。用户授权美化现有原生 Android 录入页，并要求尽量减少默认界面样式。本轮使用 Product Design 的界面检查流程，直接改造现有 Kotlin / Compose 工程。首版主界面检查记录保存在 `docs/verification/v1.2/design-qa-prior.md`。

## 目标与视觉依据

- 范围：新增/修改页、日期滚轮、修改考试选择、超分核对；保留原有成绩规则与数据保存方式。
- 风格依据：`docs/ui-preview-v1.png` 的纯黑、荧光绿、青色、白/灰文字与克制分隔线。
- 原界面：`docs/verification/v1.2/editor-before.png`，实际 1.1 安装包，2400 × 1080 / 420 dpi，空数据库、默认语数英、未打开输入法。
- 最终界面：`docs/verification/v1.2/release-editor.png`，实际优化后的 1.2 安装包，同一模拟器、尺寸、字体、日期、空数据库与默认科目。
- 全屏同屏对照：`docs/verification/v1.2/comparison-full.png`，上下等比例归一化为 1200 × 540；原始截图不改动。
- 字段局部对照：`docs/verification/v1.2/comparison-fields.png`，使用旧/新相同小数和零分录入场景。旧版单栏滚动与新版两侧独立滚动的位置有意不同，局部裁切只用于观察字段、标签和颜色，不作为相同布局的像素比对。

## 发现、修正与复验

| 发现 | 修正与证据 |
| --- | --- |
| [P2] 原页重复浮动标签、宽边框与单栏堆叠，占据大量横屏高度，初始成绩行基本不可见。 | 自定义双栏：左侧考试信息/备注/选科，右侧成绩表/总分排名；表格共享列标题。最终空页面可直接查看三科成绩入口。`comparison-full.png`。 |
| [P2] 首轮自定义弹层触发状态栏和导航栏出现，影响沉浸式风格。 | 对弹层窗口沿用应用的沉浸式系统栏行为。最终安装包截图 `release-editor.png`、`release-editor-existing.png`。 |
| [P2] 滚动后列标题可能离开视口，较多科目或键盘下难以辨认当前字段。 | 固定成绩列标题；左右各加持续可见的细滚动位置提示。`large/editor.png`、`small/editor-keyboard.png`。 |
| [P2] 总分摘要横排在短屏及多种总分时可能挤占操作区。 | 分别采用标签/数值两行的弹性列，固定保存与取消；长摘要省略显示，输入字段支持水平滚动，精确数值不截断保存。`small/editor-official-totals.png`、`font-120/editor-official-totals.png`。 |
| [P2] 空输入提示亮度偏低。 | 提高提示文字亮度，聚焦用荧光边线，裸分和赋分数值分别使用绿/青色。`release-editor.png`、`comparison-fields.png`。 |
| [P2] 用户反馈首轮重设计的栏目仍偏大、可视信息少。 | 输入框压到约 34 dp，成绩间隔 5 dp；左侧标签与字段同行，选科块 26 dp；顶部/底部分别压到 46/52 dp。常规横屏同屏显示四项信息、九个选科选项与六科成绩，`large/editor-empty.png`。同状态压缩前/后对照：`comparison-density.png`。 |

## 表面与交互检查

| 表面 | 结论与证据 |
| --- | --- |
| 字体和层级 | 标题、分组、列标签、数值有明确层级；字体沿用 Android sans-serif / 中文字库。正常/短屏/120% 字体均实测。 |
| 布局和间距 | 宽屏双栏、顶部模式切换、底部固定摘要与保存；两侧滚动互不影响，屏幕挖孔安全区保留。 |
| 颜色和材质 | 背景 `#090C0D`，输入面 `#151A1C`，细线 `#283034`，强调使用现有 `#B3FF47` / `#36DDEB`；无大阴影或装饰背景。 |
| 输入控件 | 应用自行设计的 `BasicTextField` 装饰、静态标签和表格字段，保留可访问的字段名称和原始值。输入法完成键收起键盘并恢复保存；焦点字段自动滚入视口。 |
| 科目选择 | 九科网格块，明确选择状态与可访问语义；移除/加入科目后字段同步，赋分仅在适用科目出现。 |
| 日期 | 三列滚轮、中心选中带、顶部日期预览；可滑动/点击。2024-01-31 → 2024-02-29 → 2023-02-28 的边界验证通过。`large/editor-date-month-end.png`。 |
| 历史考试选择 | 同风格的名称/日期/学期列表、选中标记与明确确认操作。`large/editor-exam-picker.png`。 |
| 超分核对 | 自定义提示面和两项操作；返回时数据未写入，确认后保留输入值。`large/editor-over-max.png`。 |
| 实际优化安装包 | 空数据与从旧版保留的历史数据均打开编辑页成功。`release-editor.png`、`release-editor-existing.png`，无崩溃日志。 |

## 有意差异与边界

此次是授权的界面重设计，双栏、共享表头、静态标签及自定义弹层有意替换旧版布局，并不要求复制旧页的几何形状。系统输入法保留以支持中文录入、粘贴和用户键盘偏好；备份用的系统文件选择器沿用 1.1 行为。

短屏需要滚动查看其他科目和总分字段，边缘的部分行会被正常裁切；当前编辑字段、列标题及收起输入法后的保存操作可访问。非常长的数值可在输入框内水平滚动，底部预览使用省略号，不改写存储精度。截图含测试用成绩，仅出现在测试代码/模拟器/验证文件中，首次安装无示例数据。

本轮为模拟器内部检查；实机、不同厂商输入法与 Android 10 尚未运行。无未解决的 P0/P1/P2；用户最终视觉反馈仍以安装后的体验为准。
